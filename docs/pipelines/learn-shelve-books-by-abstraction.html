收拾书：先按概念抽象层，再按数目类别

整理书架/书桌时，先用「抽象程度」分层，再用常规类别细分，减少越理越乱

种子学习2026-10-07整理书籍抽象待完善

步骤

  1. 1
    先按抽象程度分堆

    例：元方法/原则 → 领域框架 → 操作手册 → 案例/习题 → 闲书消遣。（层级名可自定）

  2. 2
    同层内再按数目类别

    同一抽象层里才分：技术 / 人文 / 生活 / 工具书等，避免「类别」与「层级」缠在一起。

  3. 3
    进行中的书单独一区

    正在读、待读、已读归档三分开；进行中不超过视线可及的一小格。

  4. 4
    每本书只问两个问题

    「它教的是哪一层抽象？」「同类里它跟谁挤一格？」答不出就暂放待分类盒。

  5. 5
    季度复盘一次错位

    把「一直拿错层」的书上移或下移抽象层，而不是只按封面颜色重排。

心法

开门（抽层级）→ 放入（类别入位）→ 关门（常用区固定）

何时使用

书柜爆炸、找书靠翻、知识资产想可视化时。

边界

不是图书馆编目学复刻；层级为自己的认知服务，允许粗分。
