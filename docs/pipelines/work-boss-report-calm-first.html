老板汇报：先稳情绪，再按场景走步骤

汇报前先摆正「解决问题」姿态，情绪平稳后再进入场景化的 1-2-3

种子工作2026-10-07职场汇报情绪待完善

易学错觉：看懂步骤 ≠ 会做。价值在山底上路与山顶总结；中间必须亲自练。 原则全文

山底 · 快速上手

  1. 1
    平稳情绪

    开口前先确认：不是辩解场、不是诉苦场；身体放松、语速放慢。

  2. 2
    摆正解决问题的姿态

    默认站位是「一起把事推进一步」，不是「证明我没错」。

  3. 3
    认场景再选模板

    例：日常进度 / 坏消息 / 要资源 / 复盘决策…（场景表待补）

  4. 4
    场景内走 1-2-3

    通用骨架可先用：现状一眼 → 原因/选项 → 我建议的下一步与需要的支持。（各场景细则待写）

  5. 5
    结尾对齐动作

    确认老板听到的「下一步」和你说的是同一件；记下谁在何时跟进。

山顶 · 深度体悟

待实践：各场景下「现状一眼→原因/选项→下一步与要支持」的压缩话术，以及情绪过线时的真实熔断信号。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

开门（稳情绪+姿态）→ 放入（场景步骤）→ 关门（对齐下一步）

何时使用

向上同步、尤其有压力或数据难看时。

边界

坏数据怎么找亮点见 work-bad-data-highlight-six-steps；本条先解决「人与姿态」，再谈话术结构。
