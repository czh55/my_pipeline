易学错觉：看懂步骤 ≠ 会做。价值在山底上路与山顶总结；中间必须亲自练。 原则全文

山底 · 快速上手

  1. 1
    先写读者疑问（禁止先写目录）

    按 Q1–Q6 写清读者会问什么与必须交出的东西：结论与范围；尺子与缺口；3±1 条带数发现；差异拆解全表；不确定处；建议与数据锚点。写不全不开正文。

  2. 2
    按疑问装填（通俗，不删数）

    每个 Qi 先一句人话，再跟完整数据块（分项/原单位，可进附录但正文能指到），再一句「所以这意味着…」。禁止合并分项、只报涨跌不报基期、用未解释的综合指数代替算法。

  3. 3
    词表消毒

    只用日常汉语或读者岗位已默认会的词。候选新词三选一：删掉 / 换成旧词 / 改成一句描述。没看过资料的人读标题小标题，凡需口头解释的词一律改掉。

  4. 4
    按疑问重排

    正文顺序=Q1→Q6；资料原章节只当证据柜；映射不上的进附录或删结构（删结构不删数据）。

  5. 5
    交付三检

    检通俗不删数、无新词、疑问序；失败则补数、改词或按 Q1–Q6 重排。

山顶 · 深度体悟

待实践填充。硬原则保持原文：①通俗但不删数据；②没有新定义词汇，写给第一次阅读的人；③顺着读者的疑问组织结构，而不是按照资料本身的结构。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

通俗但不删数据；没有新定义词汇；顺着读者的疑问组织结构，而不是按照资料本身的结构

何时使用

有数据要交代、读者多半第一次看、目标是「读完能做判断」——不是展示读过多少资料。

边界

没有可核对数据时不要硬写「发现」；资料原目录不能直接当大纲。
