work-reduce-negative-attitude

如何减少对工作的消极态度

遇到烦事时先分型处置，避免对立叙事或妖魔化把事情写死

草稿工作自己定义2026-10-09work心态自己定义

易学错觉：看懂步骤 ≠ 会做。价值在山底上路与山顶总结；中间必须亲自练。 原则全文

山底 · 快速上手

  1. 1
    先分型：中性还是恶性？

    中性=累烦但不想「对方存心害我」；恶性=脑内已贴坏人/坏局标签。分不清先按中性；只有明确伤害/违规证据才升级对策，而不是升级骂名。

  2. 2
    中性——找共通能力

    问三句：剥掉公司任务外壳我在练什么能力？生活里哪里也用得上？今天最小可完成的一截是什么？写一行对照，例如：汇报→把复杂事说清→旅行协调同样用得到。

  3. 3
    恶性——先停妖魔化

    ①还原原句成中性事实；②拆必然——是已经坏定了还是提前写成结局；③留空隙——证据不足前禁止用结论空转。有具体侵害再谈边界与行动。

  4. 4
    当日收束（30 秒）

    今天是中性还是恶性？用了哪条原则？有没有把「不一定坏」说成「必然坏」？有则改回事实句。

山顶 · 深度体悟

硬原则原文： 1. 中性的事情调整心态：不要把自己的事情和工作的事情对立，他们的工作内容不同，但是对人训练的能力是共通的。比如果汇报能力就是沟通能力，团队能力就是就是你出去玩的组织能力 2. 恶性的事情调整心态：不要下意识恶化别人和事情，所谓的妖魔化。否则很容易沉溺在消极的情绪中，让本身不一定坏的事情变成必然的坏

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

中性事找共通能力；恶性事先停妖魔化

何时使用

察觉自己在用对抗/受害/对方很坏的叙事看工作，或事还没做完情绪已先判死刑时。

边界

不把情绪标签当侵害证据；真正违规仍要处理，但先还原事实。
