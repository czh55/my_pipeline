learn-scene-english-from-video

视频场景 → 中英对照开口卡

把真实情景对话切成可替换说法的场景英译页，用来练嘴而不是做摘要

草稿学习2026-10-07英语场景paraphrase

步骤

  1. 1
    收 URL 或出队

    Webhook / Issue / pending-urls.txt cron 取一条；下载音频与可选视频流。

  2. 2
    转录并切 4–12 场景

    Whisper 后按情景切块；每句 cn/en/note + paraphrase（可替换说法）。

  3. 3
    配音与抽帧

    edge-tts + 场景帧 → docs/audio、docs/images。

  4. 4
    生成场景英译页

    产出 *-场景英译.html（或以 WORKFLOW 为准的卡片页）；更新 index.json。

  5. 5
    发布并可导入学习站

    push main；需要时 english-system import-from-paraphrase 进入统一学习壳。

心法

开门（视频）→ 放入（切场景英译）→ 关门（HTML + 可选导入 english-system）

何时使用

目标是「下场能开口」，而不是「看懂视频讲了什么」。

边界

与 video-notes 双轨总结分流——本条不做理性分析长图；语料少时先积卡再导入系统。

来源

language_paraphrase WORKFLOW；video-notes 场景英译支路；english-system 消费层
