山底 · 快速上手

  1. 1
    认场景

    室内人像 / 户外顺光 / 逆光 / 夜景 / 运动拖影…（场景表待补全）

  2. 2
    场景内第 1 步：曝光锚点

    先定谁正确曝光（脸 / 天空 / 主体高光），再动其余。（各场景细则待写）

  3. 3
    场景内第 2 步：景深与焦段

    光圈/距离/焦距服务主体分离还是环境交代。（待按场景填）

  4. 4
    场景内第 3 步：快门与稳定

    手持极限、是否需要三脚架/连拍/防抖。（待按场景填）

  5. 5
    试拍一张再锁定

    看直方图与成片意图，再批量拍；不边拍边无目的拧盘。

山顶 · 深度体悟

待实践：每个场景真正「锁死」的参数顺序与容错范围，需按机身实测后回填。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

开门（认场景）→ 放入（按序设参）→ 关门（试拍确认）

何时使用

出门前或到场后，需要快速进入「可拍状态」而不是研究菜单时。

边界

不同机身菜单不同，章程记的是决策顺序，不是某一品牌键位教程。
