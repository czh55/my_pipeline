室内蜡黄发暗时，用基础参数 + HSL 把肤色拉回清透

易学错觉：看懂步骤 ≠ 会做。价值在山底上路与山顶总结；中间必须亲自练。 原则全文

山底 · 快速上手

  1. 1
    全局打底

    提亮度、略降对比（奶油感）、加饱和，微调光感/锐化。

  2. 2
    HSL 橙色去黄提亮

    降橙色色调/饱和度去黄，再提橙色亮度——皮肤主要由橙色通道控制。

  3. 3
    逐色修环境色

    衣服/水果/背景各色单独调，避免只有脸干净、环境发脏。

  4. 4
    高光阴影塑形

    微调高光/阴影增加立体层次，避免全局后画面扁平。

  5. 5
    冷色温收尾

    略偏冷收束清透感；顺序坚持「全局→HSL→高光阴影→色温」，勿一步全局色温糊弄。

山顶 · 深度体悟

待实践填充——山顶体悟只在练过之后写，不在看懂步骤时编。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

开门（全局打底）→ 放入（橙通道去黄提亮）→ 关门（塑形+冷色温）

何时使用

室内暖光/混合光人物视频、手机自拍「人比实际黄」的画面。

边界

户外强光充足画面不是提亮题；刻意暖黄怀旧风不要硬救成冷白皮。
