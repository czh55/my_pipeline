易学错觉：看懂步骤 ≠ 会做。价值在山底上路与山顶总结；中间必须亲自练。 原则全文

山底 · 快速上手

  1. 1
    收链接并识别平台

    Webhook / 手工拿到 url+date；detect-platform；查 index.json 去重，已处理则停。

  2. 2
    限流下载音视频

    B 站用 yt-dlp；小红书用 xhs-fetch + 全局限流（≥60s），禁止探测式连环请求。

  3. 3
    Whisper 全量转录

    优先 medium；读完全部 segments，不以标题/前 30 秒代替证据。

  4. 4
    双轨编辑与配图

    同证分叉——HTML 按时序纪实+截图图注；SVG 重组论点/边界/行动清单；简体中文为主。

  5. 5
    更新索引并合入 main

    写 docs 产物与 index.json；开发分支提交后必须 merge 并 push main（Pages 只认 main）。

山顶 · 深度体悟

待实践填充——山顶体悟只在练过之后写，不在看懂步骤时编。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

开门（取证下载）→ 放入（转录双轨编辑）→ 关门（索引 + main Pages）

何时使用

想把一条短视频/教学视频变成「能重看 + 能照做」的知识资产时。

边界

不是场景英译流水线（那是 language_paraphrase）；修旧文默认不重抓小红书；能力不足时宁留草稿不发残缺页。
