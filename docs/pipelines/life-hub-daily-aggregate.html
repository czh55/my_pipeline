life-hub-daily-aggregate

Daily Hub 日聚合：抓子站 → feed → 房子侧栏

中午把各生活子站摘要收进一座「家」，不覆盖 3D 首页，只更新可读目录

已验证生活2026-10-07日更聚合家

步骤

  1. 1
    读子站清单

    scripts/generate.py 读取 data/config.json（摄影/算法/播客/歌词/技术/剧集/旅行等）。

  2. 2
    逐站抓 HTML 摘要

    GET 各 Pages；抽 title/meta/首段；单站超时失败不中断整批。

  3. 3
    写 feed 与卡片目录

    更新 docs/feed.json、list.html、archive/YYYY-MM-DD.html、history；绝不覆盖 3D index.html。

  4. 4
    提交并验门户

    commit + push；打开 chenzhiheng.cn/daily-hub 看侧栏/卡片是否刷新。

心法

开门（读配置）→ 放入（抓摘要）→ 关门（feed/归档 push）

何时使用

子站已有日更或新产出，需要「家里」一眼看到今天发生了什么。

边界

Hub 不生产子站内容；子站挂了只记 error，不在这里重跑媒体流水线。

来源

daily-hub Automation cron 12:00；archive ≈37 天；挂接 11+ 子站
