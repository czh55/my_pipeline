山底 · 快速上手

  1. 1
    收小宇宙链接

    Webhook 解析 xiaoyuzhoufm URL；浏览器 CDP 取 audio src 与标题；同 URL 只处理一次。

  2. 2
    限流下载并转录

    rate-limit 后 curl 下 m4a；Whisper（默认 small）；禁止并发多 URL 打爆 CDN。

  3. 3
    按规范写深度总结

    区分嘉宾/主持人；强制产出行动清单、避坑、时间轴与可复核论点，拒绝空泛金句墙。

  4. 4
    生成 SVG / HTML / 语音

    generate mjs → buildSvg；可选 generate_svg_audio、svg-to-html；归档转录索引。

  5. 5
    更新 index 并 push main

    prepend docs/index.json；提交后必须上 main；清理临时 m4a 与一次性脚本。

山顶 · 深度体悟

待实践填充——山顶体悟只在练过之后写，不在看懂步骤时编。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

开门（取音频）→ 放入（转录深挖）→ 关门（SVG/HTML + main）

何时使用

听完一集想留下「下次还能用」的笔记墙时（早餐餐厅场景）。

边界

仅小宇宙；与原创播客大纲流水线（my_podcast）不同——本条是消费他人节目。
