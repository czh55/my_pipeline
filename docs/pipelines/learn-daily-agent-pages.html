learn-daily-agent-pages

日更学习页：选题 → Agent 精讲 → 校验 → Pages

用日历驱动，每天稳定产出一页可学内容（算法 / 歌词等），绝不发占位残页

滚雪球学习2026-10-07日更Automation算法歌词高频

步骤

  1. 1
    跑选题脚本

    algo：generate.py --bank；lyric：generate.py --prepare；读写 history 保证去重轮换。

  2. 2
    按方法论补齐内容

    算法走变量语义法（认型→三句→落码）；歌词按 lyric-learning-prompt 逐句精讲；缺精讲则 Agent 补全后再 --force。

  3. 3
    可选语音

    edge-tts 生成当日讲解音频，挂到页面可播。

  4. 4
    强制校验

    check_pages / finalize；algo 禁止日常 --allow-auto 占位页上线。

  5. 5
    提交日更

    更新 index、archive/lessons、history；commit 信息用 daily: YYYY-MM-DD → push main → 打开站点确认。

心法

开门（脚本选题）→ 放入（按模板写精讲）→ 关门（check + push main）

何时使用

书房日课——需要「每天都有一页」的长期能力滚雪球时。

边界

与 Webhook 媒体流水线不同；内容质量门禁优先于准时——写不出完整精讲就当天停更，不发空壳。

来源

daily-algo（≈66 天, cron 08:00）+ daily-lyric-learning（≈72 课, cron 08:00）+ daily-photos 同构壳
