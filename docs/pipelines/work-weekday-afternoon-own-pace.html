工作日下午：自己控节奏，插课间

下午难熬时靠「提前规划 + 自定课间」撑住节奏，而不是盲从周围人的作息硬扛

草稿工作自己定义2026-10-28work节奏课间自己定义

易学错觉：看懂步骤 ≠ 会做。价值在山底上路与山顶总结；中间必须亲自练。 原则全文

山底 · 快速上手

  1. 1
    下午开场先画板

    开工前 3 分钟写出：今天下午要完成的 1～3 块事、每块大致起止、中间插几次课间（各几分钟）。不写「忙一下午」这种空口号。

  2. 2
    按自己的块推进，不跟场

    周围人开会、摸鱼、加班都不自动变成你的时钟。你的块没到点就不切；到点就切，哪怕别人还在硬扛。

  3. 3
    课间当真休息

    课间离开工位或换姿势：走几步、喝水、望远。不用刷信息流顶替休息；时间到立刻回下一块。

  4. 4
    收束不绑架

    计划块做完就收；别人「还在干」不等于你欠班。明日上午再开新板，不把疲惫当成责任感。

山顶 · 深度体悟

待实践：自己的最佳课间间隔（45/60/90？）；哪类任务适合短冲、哪类适合长块；什么信号说明已经在盲从作息。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

开门（先定自己的下午节奏）→ 放入（按块执行并插课间）→ 关门（收束不跟风加班叙事）

何时使用

工作日午后犯困、拖沓、或看着别人节奏开始焦虑「是不是该一直坐着」时。

边界

有硬截止或协同会议时，先守外部时间点，再在缝隙里插课间；不是用「自己控节奏」逃避承诺。情绪已崩到对立叙事时，先用 work-reduce-negative-attitude。
