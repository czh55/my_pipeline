易学错觉：看懂步骤 ≠ 会做。价值在山底上路与山顶总结；中间必须亲自练。 原则全文

山底 · 快速上手

  1. 1
    认议题类型

    关心健康 / 干预选择 / 金钱 / 节日安排… 不同类型用不同模板（待分）。

  2. 2
    先接住关心，再谈边界

    承认对方动机里的善意，再清晰说出自己的决定边界。

  3. 3
    少讲道理，多给具体安排

    用时间、方案、备选代替抽象原则辩论。

  4. 4
    冲突升级时换频道

    待补：暂停信号、改日再谈、引入第三方缓冲等。

  5. 5
    留下可执行的小约定

    一次沟通只推进一件小事，滚雪球式建立信任。

山顶 · 深度体悟

待实践：哪类议题必须先接住关心、哪类必须先立边界；家庭差异大，不可照搬别人话术。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

开门（认议题类型）→ 放入（边界+关心并提）→ 关门（可执行约定）

何时使用

代际沟通反复卡在同一话题时。

边界

强占位；家庭情况差异大，必须用亲身回合改写。
