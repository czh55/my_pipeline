山底 · 快速上手

  1. 1
    不急躁

    先稳住呼吸与注意力；急躁只会同时丢掉「正在做的」和「突发的」两边质量。允许自己用几十秒确认：这是插入，不是世界崩了。

  2. 2
    当前与近期事项入槽留存

    快速梳理手头与近期待办，写进明确的槽位（今日未完 / 本周待办 / 已约时间块），状态与下一步动作各记一句，避免只靠脑子硬扛导致遗漏。

  3. 3
    切换做突发事项

    入槽完成后再全力处理突发；切换时心里清楚「被停住的事已经有位置」，降低焦虑驱动的多线程乱切。

  4. 4
    舒缓时段补齐槽内事项

    突发结束后，选节奏相对松的时段（当日尾声、次日上午、本周缓冲块）按槽位逐条补齐或改期，不默认「做完突发等于可以忘掉被挤掉的事」。

  5. 5
    用周期松紧做平衡，不追求天天天天一样

    一周/一月内，每天松紧本来就不会均匀；紧日靠入槽保不失，松日靠回补还债。调节的是周期平衡，不是强迫每日同强度。

山顶 · 深度体悟

待实践：自己的「槽」具体落在哪（日历块/便签栏）、舒缓回补通常落在一天里的哪一段最稳。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

开门（不急躁）→ 放入（事项入槽）→ 关门（节奏回补）

何时使用

老板/客户/家庭突然插单、原计划被打断、容易又慌又怕漏事时。

边界

入槽不是拖延突发；真正紧急且不可延后的事项仍优先处理，但「入槽」这一步尽量压成一两分钟。也不等于无限承接一切突发——周期过载时要显式砍范围或求助。
