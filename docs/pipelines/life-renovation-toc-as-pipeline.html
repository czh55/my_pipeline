装修：把书的目录当成 pipeline 骨架

同一主题不同作者有不同目录；先拿来主义当骨架，边学边做，再沉淀自己的目录结构

种子生活2026-10-07装修目录拿来主义待完善

步骤

  1. 1
    选 1–2 本靠谱框架书

    先抄目录，不先抄细节技巧；目录=阶段划分候选。

  2. 2
    把目录改写成阶段 pipeline

    每章变成：目标 / 输入 / 决策点 / 产出 / 常见坑。（例：需求→设计→拆改→水电→泥木…）

  3. 3
    边做边标注「我的版本」

    哪一步书上有但自己用不上、哪一步书上没有但现场必需——写进自己的 YAML。

  4. 4
    决策点单独列表

    预算、风格、收纳、工期、住不住人施工… 每个决策点有选项与代价。

  5. 5
    收工后定稿自己的 TOC

    下次装修/局部改造只带自己的目录上山，不再从零找书。

心法

开门（借目录）→ 放入（实践改写）→ 关门（收成自己的 TOC）

何时使用

装修、局部改造、或任何「书很多但不知道按啥顺序做」的大项目。

边界

目录能帮山底上路，不能替代工地实践；不同城市工艺与规范不同，必须本地化。

来源

用户主题清单 2026-10-07（核心方法：目录即 pipeline）
