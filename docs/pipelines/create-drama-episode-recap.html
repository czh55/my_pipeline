create-drama-episode-recap

本地剧集 → 一集剧情总结站

把已下载的一集电视剧变成可检索的图文剧情回顾（情节/台词/人物/伏笔）

滚雪球创作2026-10-07剧集Whisper追剧高频

步骤

  1. 1
    锁定剧集与文件

    确认 drama / episode / 本地 mp4 路径；维护 cast.md（演员与角色）。

  2. 2
    转录并切关键场景

    faster-whisper / Whisper 出 JSON；按地点·事件·情绪切 8–12 场景，写叙述与关键台词。

  3. 3
    抽帧与台词英译配音

    ffmpeg 按场景时间抽帧；台词补 EN；必要时 edge-tts 生成引用朗读。

  4. 4
    渲染单集 HTML

    产出含梗概/情节/人物/看点/伏笔/启示的单文件页，资源进 docs/images。

  5. 5
    校验索引并发布

    validate → 更新 index.json / 搜索索引 → commit docs+content → push main。云 Agent 只负责索引推送，不读本地盘。

心法

开门（本地视频）→ 放入（转录切场景）→ 关门（HTML + 索引 push）

何时使用

追剧后想留下「下周还记得发生了什么」的回顾资产时。

边界

视频不入库；无本地片源不要硬跑；半自动时人工完成转录编辑再触发 push。
