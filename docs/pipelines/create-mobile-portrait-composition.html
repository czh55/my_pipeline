create-mobile-portrait-composition

手机单人出片：机位高度 + 距离 + 网格

用固定机位参数替代「不会构图」，在站/半身/蹲/坐下稳定比例与自然感

已验证创作自己定义2026-10-07摄影手机构图video-notes

易学错觉：看懂步骤 ≠ 会做。价值在山底上路与山顶总结；中间必须亲自练。 原则全文

山底 · 快速上手

  1. 1
    开网格并定姿势类型

    打开相机网格线；先选全身 / 半身 / 蹲姿 / 坐姿之一，不要边摆边猜机位。

  2. 2
    全身——对齐胸口、后退约 2m

    被拍者站立，手机约对齐胸部高度，人物落在中下两格，避免仰拍畸变。

  3. 3
    半身——对齐鼻子、1.5×、外翻约 15°

    镜头对齐鼻子附近，后退约 1.5m，1.5× 变焦，机位微外翻；眼睛对齐取景框顶线。

  4. 4
    蹲姿同步蹲下

    拍摄者先蹲再构图；手机与脸平行、1.5×；侧身对镜头，头顶卡顶线。

  5. 5
    坐姿走对角线

    让人走到画面一侧再后退约 1m，形成对角线，避免正面呆板。

  6. 6
    每种连拍 3 张回看

    回看机位与网格是否达标；半身重点练「外翻 15°」手感。

山顶 · 深度体悟

待实践填充——山顶体悟只在练过之后写，不在看懂步骤时编。

实践踩坑

尚无踩坑记录。每练一轮，在 YAML 的 practice 里追加一行 date + note。

心法

开门（开网格定姿势）→ 放入（对机位）→ 关门（连拍回看）

何时使用

单人日常光线、主摄约 24–28mm 等效；想快速出片而不是研究复杂构图理论时。

边界

不适于多人合影、身高差极大、竖屏全身需重校距离；主题优先时先钉「拍什么」再调机位。
