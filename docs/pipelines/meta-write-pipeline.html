meta-write-pipeline

如何把一次经历写成 pipeline

把「刚经历过的事」沉淀成可复制章程，而不是散落的印象

草稿元原则2026-10-07meta写作滚雪球

步骤

  1. 1
    定一件具体的事

    只选最近一次真实经历（例如「周三做了西红柿炒蛋」），拒绝抽象口号。

  2. 2
    写出意图

    一句话说清「下次再遇到同类事，希望稳定得到什么结果」。

  3. 3
    拆有序步骤

    按时间顺序写 3～7 步；每步必须是可执行动作，不是形容词。

  4. 4
    标适用与边界

    when_to_use 写触发条件；boundaries 写什么时候别硬套。

  5. 5
    标状态并入库

    新建 YAML，status 从 draft 起；跑 render-site.py 挂到站点。

心法

开门（回忆）→ 放入（抽步骤）→ 关门（写边界与状态）

何时使用

刚办完一件事、觉得「下次还能更快/更稳」时，立刻写。

边界

没有亲身经历时不要硬编；可先用 seed 占位，等经历来了再填。
