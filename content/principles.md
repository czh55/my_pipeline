# 底层原则

## 大象进冰箱

如何把大象放进冰箱？

1. 开门
2. 放入
3. 关门

笑话的外壳下面，是一条跨行业、跨场景的底层原则：

> **解决问题、做事，都有步骤和章程。**

做饭有步骤，沟通有步骤，学习有步骤，拍摄有步骤；工作任务、汇报也有步骤。你尚未经历的事，同样需要这套原则——只是步骤要等经验来填。

## 本仓库在做什么

不是收集别人的「最佳实践清单」，而是：

1. 经历一件事
2. 抽出可复用的步骤
3. 写成 pipeline，标明适用与边界
4. 下次同类事直接照章程走，再反馈修订

能力像滚雪球：章程越多、越贴合你自己的生活，雪球越大。

## 领域

| domain | 覆盖 |
|--------|------|
| `meta` | 原则本身、如何写 pipeline |
| `life` | 做饭、出行、家务等日常 |
| `communicate` | 对话、关系、表达 |
| `learn` | 学习、复习、吸收 |
| `create` | 拍摄、写作、制作 |
| `work` | 任务、汇报、协作 |

## 状态阶梯

- `seed`：占位或隐喻，提醒原则，尚未绑定亲身经历
- `draft`：刚从一次经历抽出，待再跑一轮
- `validated`：自己用过多次，步骤靠谱
- `snowball`：已能教人 / 跨场景复用，进入能力滚雪球
